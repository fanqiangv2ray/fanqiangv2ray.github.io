第五章：常见问题与解决方案

即使按照教程操作，也难免遇到各种“幺蛾子”。以下是最高频的问题及解决方法：

Q1: 订阅更新失败，提示“解析错误”怎么办？

这通常意味着订阅链接返回的数据格式不正确。可能原因包括：链接已过期、服务器返回了错误页面、或者订阅源格式不兼容。解决方案：尝试更换其他订阅源；检查链接是否完整（注意不要复制多余空格）；在客户端中清除订阅数据后重新添加。

Q2: 连接成功了，但网页加载速度极慢？

免费节点的通病就是速度不稳定。你可以尝试：切换其他节点，寻找延迟更低的线路；在客户端中开启“分流规则”（即国内流量直连，国外流量走代理），减轻服务器负担；关闭视频网站的高清自动播放功能，降低带宽占用。

Q3: 部分应用无法通过代理访问？

有些软件（如部分游戏、银行APP）会检测代理设置并拒绝连接。解决方法：在客户端的“路由设置”中，将需要直连的应用加入白名单；或者使用“全局模式”强制所有流量走代理（但会牺牲部分速度）。

Q4: 安装时被杀毒软件拦截？

如前所述，这是正常现象。在Windows中，你可以将软件目录添加到Windows Defender的排除列表；在macOS中，在“系统偏好设置-安全性与隐私”中允许应用运行。但前提是你确认下载来源可信。

  1. 绝不使用来源不明的节点——恶意节点可能窃取你的流量数据。
  2. 避免传输敏感信息——即使有加密保护，公共节点仍存在风险。

可通过调整 Hysteria2 的 `recv_window` 与 `send_window` 参数改善传输性能，同时确保服务器带宽充足。若使用移动网络，建议启用 BBR 拥塞控制并降低测速频率以减少波动。
Netch 如何区分全局代理和规则代理？
全局代理会将所有流量通过节点转发，而规则代理仅对指定 IP、端口或应用生效。用户可根据需求选择代理模式，实现流量优化和不同应用的最佳网络体验。
VMess 与 Shadowsocks 哪个更安全？
VMess 使用动态认证机制，防止重放攻击，而 Shadowsocks 依赖静态密钥。总体来说，VMess 的安全性更强，尤其在应对 DPI 检测和中间人攻击时表现更优。
Surfboard 策略组如何优化视频访问？
通过策略组将视频流量分配到低延迟、高带宽节点，Surfboard 可自动切换到最佳节点。减少缓冲和卡顿，提高在线视频播放流畅性和整体网络体验。
Clash for Android 如何导入订阅并自动更新？
在 Clash for Android 的配置界面中选择“配置文件”→“新建配置”，粘贴订阅链接即可。启用自动更新功能后，软件会定期检查订阅源是否有新节点，并在后台自动替换旧配置，保持节点最新状态。
V2Ray 的 ws+tls 传输模式有什么优点？
ws+tls 模式利用 WebSocket 伪装成普通 HTTPS 流量，使得防火墙难以区分代理与正常访问。该模式兼容性强，适合部署在支持 Nginx 或 Caddy 的 Web 服务器上。
如何用 iptables 限制 V2Ray 服务的访问来源？
使用 iptables 规则仅允许可信 IP 或 CDN 的中转 IP 访问服务端口，例如 `iptables -A INPUT -p tcp -s --dport 443 -j ACCEPT`，并在默认策略下拒绝其他来源，从而降低被扫描与滥用风险。
