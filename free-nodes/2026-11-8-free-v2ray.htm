第三章：手把手安装教程——覆盖Windows / macOS / Android三大平台

3.1 Windows平台：从下载到双击运行的60秒速通

  1. 下载核心压缩包：访问GitHub或官方镜像站，搜索“v2ray-core”或“Xray-core”，选择最新Windows 64位版本下载。注意：不要下载来源不明的“一键安装包”，安全风险极高。
  2. 解压与目录结构：将压缩包解压至D:\v2ray，你会看到v2ray.exe、config.json等文件。请记住这个路径，后续配置需要用到。
  3. 环境检查：确保系统已安装.NET Framework 4.6.2或更高版本（Win10/11通常自带）。
  4. 运行与验证：双击v2ray.exe，如果看到命令行窗口提示started且无红色报错，即代表核心已启动。但此时还没有图形界面，别急，我们稍后会用客户端接管它。

3.2 macOS平台：优雅的拖拽安装法

  1. 下载对应包：选择darwin-amd64或darwin-arm64（M系列芯片选后者）的zip包。
  2. 移动至应用程序：解压后，将v2ray-core文件夹整体拖入访达的“应用程序”目录。
  3. 解决“已损坏”提示：打开“系统设置” -> “隐私与安全性”，在底部点击“仍要打开”。这是macOS的Gatekeeper保护机制，并非软件问题。
  4. 后台运行：由于没有GUI，建议使用Homebrew安装v2ray-core并配置开机自启，或者配合下文提到的V2rayU客户端使用。

3.3 Android平台：移动端的自由开关

  1. 客户端选择：推荐使用v2rayNG（Google Play或GitHub下载）。它界面简洁，对免流配置支持良好。
  2. 安装与权限：安装时，系统会请求“建立VPN连接”的权限，必须点击允许，否则无法转发流量。
  3. 导入配置：打开v2rayNG，点击右上角“+”号，选择“从剪贴板导入”或“扫描二维码”。稍后在第四章会详细讲。

第四章：核心配置方法论——让你的节点真正跑起来

如果说安装是骨架，那么配置就是灵魂。90%的“连不上”问题都源于此。

4.1 配置文件从哪里来？（安全警告！）

  • 正规渠道：你购买的机场（服务商）后台，通常提供订阅链接或分享二维码。
  • 社区分享：某些技术论坛或Telegram群组会有公益节点，但极其不稳定且存在数据窃取风险，强烈不建议用于敏感操作。
  • 自建服务器：如果你有一台海外VPS，可以通过官方脚本生成config.json。这是最安全、最可控的方式。

4.2 手动编辑config.json——看懂这几个关键字段就够了

如果你拿到的是纯文本配置，用记事本打开，关注以下核心项：

  • "port"：本地监听端口，默认1080或10808，不用改。
  • "inbound"：入口配置。确保"protocol"为socks或http。
  • "outbound"：出口配置。重点看"protocol"是否为vmess或vless。
  • "settings"下的"vnext"：这里填写你的服务器地址、UUID（用户ID）、alterId（额外ID，老协议为0，新协议无此项）。
  • "streamSettings"：传输层配置。如果是tcp且无伪装，最容易封；建议使用ws（WebSocket）并配置Host头伪装。

新手提示：不要手动改UUID或端口，除非你清楚自己在干什么。一个标点符号错误都会导致启动失败。

4.3 使用V2rayN或QT客户端——告别记事本，拥抱图形化

这才是现代用户的主流玩法。

  1. 下载V2rayN：这是Windows上最流行的GUI客户端。
  2. 导入订阅：在V2rayN主界面，点击“订阅” -> “订阅设置”，填入你的订阅URL，点击“更新订阅”。此时左侧列表会弹出所有可用节点。
  3. 一键配置：右键选中一个节点，点击“设为活动服务器”。然后点击底部任务栏的V2rayN图标，选择“自动配置系统代理”或“PAC模式”。
  4. 测试延迟：选中节点，按Ctrl+B测试真连接延迟，选择数值最低且稳定的节点。

macOS用户：同理，使用V2rayU或ClashX Pro，导入订阅后，在“出站模式”里选择“规则判断”，即可实现分流。

第五章：实战使用技巧——如何榨干V2Ray的每一分性能

配置完成，能上网只是第一步。以下技巧能让你从“能用”进阶到“好用”：

  • 规则分流是灵魂：在客户端中，将国内IP段（geoip:cn）和国内域名（geosite:cn）设为“直连”，将国外流量设为“代理”。这样访问B站、淘宝时走本地带宽，速度快且不耗代理流量；访问Google时走代理，稳定且隐私。
  • 善用“负载均衡”：如果你有多个机场或节点，在V2rayN的“路由设置”中，可以设置balancer策略。让视频流量走大带宽节点，让聊天流量走低延迟节点。
  • 定期更新订阅：节点被墙是常态。建议设置每周自动更新订阅，并观察节点的“总流量”和“剩余流量”，避免跑满被限速。
  • 开启TCP Fast Open：在核心配置或客户端高级设置中，开启TFO（TCP Fast Open），能显著降低首包延迟，对于游戏和网页首屏加载有奇效。
  • 伪装WebSocket + TLS：如果节点支持，务必选择ws+tls传输方式。这种流量看起来就像普通的HTTPS网站访问，被精准封锁的概率降低90%。

第六章：常见问题FAQ——你踩过的坑，我都替你填平了

Q1：为什么我的V2Ray能连上，但网页打不开？ A：这是DNS污染或泄漏问题。在客户端开启“域名解析策略”为AsIs或UseIP，并勾选“防DNS劫持”。如果是手动配置，请在dns设置中加入1.1.1.1和8.8.8.8。

Q2：提示“failed to handshake with tls”是什么鬼？ A：服务器TLS证书验证失败。常见原因是系统时间不准确。请同步你的电脑时间（Internet时间设置），偏差超过5分钟就会握手失败。

Q3：为什么免流效果不明显？ A：请确认你的“免流”是指运营商流量减免。这需要你的服务器端口是运营商白名单端口（如80,443），且协议被运营商识别为普通网页访问。如果只是指“科学上网”，那免流就是伪命题。建议使用ws+tls模式，并开启header伪装。

Q4：V2Ray会记录我的浏览历史吗？ A：官方原版不记录。但如果你使用的是第三方魔改版或免费共享节点，则无法保证。安全底线：自建节点 > 付费大机场 > 免费共享。永远不要在共享节点上登录网银或输入密码。

Q5：连接速度很慢，但延迟很低？ A：可能是国际出口带宽拥堵。尝试更换节点所在地区（如从美国西海岸换到日本或新加坡）。或者在客户端的“传输设置”中，调整mux并发连接数为8，能有效提升多线程下载速度。

Potatso Lite 手动节点切换有哪些优点？
手动切换节点可以根据延迟和用途选择最佳节点，适合在节点不稳定或特殊需求下使用。虽然不支持自动订阅更新，但足够满足轻量用户对节点管理和分流的需求。
Surfboard 如何结合规则实现智能节点切换？
Surfboard 可根据规则文件和策略组自动选择延迟低、稳定性高的节点处理流量。不同应用流量可分配不同节点，优化访问速度和稳定性，减少手动切换节点的操作。
Trojan 使用自签名证书会带来哪些问题？
自签名证书无法被客户端默认信任，可能导致连接失败或需要手动安装证书。它也容易被中间人伪造识别，不利于长期生产环境安全部署，建议使用可信 CA 证书以获得更好兼容性与安全性。
Nekoray 的配置文件在哪里保存？
Nekoray 的配置文件默认保存在程序目录下的 `config.json` 中。用户可手动备份此文件以迁移配置，也可使用导入导出功能在不同设备间同步节点数据。
Mellow 如何通过配置实现多出口分流？
Mellow 可在配置文件中定义多个 outbound，并结合 routing 规则实现按域名、IP 或策略组分流。这样不同类型的流量可走不同节点，提高使用体验。
